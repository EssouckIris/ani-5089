Ce qui a change : le dossier courant, c'est-a-dire le dossier d'ou le programme est lance. Le code est identique dans les quatre essais, mais le chemin relatif murs/mur.jpg est cherche a partir de ce dossier. Depuis le dossier du projet, le fichier existe a cet endroit : charge 1. Depuis Build/Bin/Debug-Windows/ch5exo6/, il n'existe pas : charge 0, image de 0 x 0, sans plantage et sans message.

Ce que LocateResource essaie : d'apres le commentaire de NkPath.h, dans cet ordre, et dans chaque dossier toutes les variantes avant de passer au suivant : 1. le dossier courant ; 2. le dossier de l'executable ; 3. les parents de l'executable, 8 niveaux au plus ; 4. les parents du dossier courant, 8 niveaux au plus. Il rend le chemin absolu trouve, ou une chaine vide, et un avertissement au journal nomme la ressource et liste les dossiers essayes si rien n'est trouve (sauf si warnIfMissing vaut false). Depuis Build, il a trouve murs/mur.jpg en remontant les parents de l'executable.
